# Dog vs Cat Classification using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify images into two categories: Dogs and Cats.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Google Colab

## CNN Architecture
- Conv2D
- ReLU Activation
- MaxPooling2D
- Flatten
- Dense
- Dropout
- Sigmoid

## Model Training
- Dataset: Cats and Dogs
- Image Size: 150 × 150
- Batch Size: 32
- Epochs: 10
- Optimizer: Adam
- Loss Function: Binary Crossentropy

## Features
- Automatic dataset downloading
- Image preprocessing and normalization
- CNN model training
- Accuracy and loss visualization
- Dog and cat image prediction
- Automatic testing on 10 validation images

## How to Run
1. Open the notebook in Google Colab.
2. Run all cells.
3. Train the CNN model.
4. Upload an image or run automatic testing.
5. View the prediction.
